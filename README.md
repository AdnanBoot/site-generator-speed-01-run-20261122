An original, faster, dependency-free drop-in replacement for `makefun-site 1.0.0`. `solve.js` exports `run(input)` returning `makefun-site`'s exact output tree for a case, and `main.ts` is the Node 22 harness driver.

## Run it

```sh
MAKEFUN_INPUT_DIR=<dir with cases.json> MAKEFUN_OUTPUT_DIR=<out dir> node main.ts
```
